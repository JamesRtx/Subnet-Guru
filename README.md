# 🌐 Subnet Guru

**Subnet Guru** is an interactive educational web app designed to make learning IP subnetting simple, visual, and intuitive.  
It combines subnet calculators, quizzes, and teaching modules to help users understand core networking concepts through guided practice.

🔗 **Live Site:** [SubnetGuru](https://main.d24a89pch8si6k.amplifyapp.com/)

---
